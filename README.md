# Transfer Photo

**Transfer Photo** is a simple web application that allows users to upload photos, display them with a 360-degree background effect, and edit image-related information such as name and upload date.

---

## 📸 Features

- Interactive 360-degree background on the homepage.
- Upload and display images with date and time of upload.
- Edit user data: change the name or replace the uploaded image.
- Clean, user-friendly interface.
